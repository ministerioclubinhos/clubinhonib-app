# Teacher Area Module

The Teacher Area is the central hub for club leaders and teachers to manage their activities, report data, and access resources.

## 📁 Key Files

- **Pages**:
  - `src/pages/TeacherArea/TeacherArea.tsx`: Main dashboard for teachers.
  - `src/pages/TeacherArea/components/`: Sub-components for identifying teacher's clubs.
- **Features**:
  - `src/features/pagela-teacher/`: Logic for reporting class attendance and data.
  - `src/features/image-sections/`: Logic for uploading and managing shared images.

## 🍎 Features

- **Club Management**: View assigned clubs and their details.
- **Reporting**: Submit weekly reports on attendance, bible study, and activities (Pagela).
- **Resource Access**: Access weekly materials (PDFs, videos, images) prepared by the administration.
- **Media Upload**: Share photos of club activities directly from the dashboard.
- **Share an idea**: The dedicated `/compartilhar-ideia` flow asks for an idea title and description, then accepts up to 20 PDF/DOC/DOCX documents, JPG/PNG/WEBP/GIF images, MP4/WEBM videos, or YouTube links. Each file has a per-type size limit; media captions are generated by the API. Submission confirmation appears as soon as the API saves the idea.
- **Feedback**: Submit feedback about the platform or materials.

### Shared idea submission (phase 1)

`IdeaShareForm` is dedicated to this flow. `useIdeaShareForm` owns the RHF/Yup draft, including materials; transport remains in the feature hook/API. The obsolete Redux draft and generic user creator are removed. Desktop content uses 95% width with text/materials side by side; mobile uses 98% and a fixed submission bar with safe-area spacing.

Teachers select Documento, Imagem or Vídeo before adding files. Only Vídeo exposes the alternative YouTube input. Supported formats/limits are explained beside the upload control. Grouped previews support remove/undo. Field errors preserve focus and API failures preserve the draft with a retry action. Navigation uses the shared unsaved-change guard; temporary preview URLs are revoked on reset/unmount.

A successful `201` immediately shows “Ideia recebida”, with explicit actions to share another idea or leave. When automatic AI is enabled, the success message explains background processing; the form never waits for AI or email. The submission notice also explains possible admin-initiated AI processing and preservation of the original.
